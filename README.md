# Mobile Trainer (Japan)

A disassembly of **Mobile Trainer (Japan)** for the Game Boy Color.

Builds the original ROM byte for byte:

- `Mobile Trainer (Japan).gbc`
  SHA-256: `6d802e66b54f700aa8c767dd4a3b9df200bae05e07a296fffb16ebf4efc76570`
