# Dynamic trace summary

Generated by `tools/trace/run_trace.py` (do not edit). See `docs/research/dynamic_tracing.md` for method and limits.

* ROM: `baserom.gbc` sha256 `6d802e66b54f700aa8c767dd4a3b9df200bae05e07a296fffb16ebf4efc76570`
* Emulator: mGBA fork (libmgba 0.11, Mobile Adapter GB support via libmobile), source commit `f8ec8e546`, built out of tree from the source tree (the pre-built binaries in `build-noble` are older than the sources and were **not** used).
* CPU model: CGB (ROM header 0xC0), HLE boot (no BIOS), SRAM 0xFF-filled unless a scenario chains a previous save.
* Coverage = instruction-start addresses actually executed. **Absence of coverage proves nothing.**

## Files

* `coverage_<s>.tsv`, `mbc_writes_<s>.tsv`, `serial_<s>.tsv`: primary evidence per scenario (formats in `docs/research/dynamic_tracing.md`).
* `detail/<s>/`: `callgraph`, `irq`, `irqsum`, `hwregs`, `ramcode`, `dataaccess`, `serialsum`, `mbc_seq`, `marks`, `adapter.log`, `stats.txt`.
* `inputs/<s>.macro` (readable source) and `inputs/<s>.txt` (resolved frame script that is replayed).
* `scenarios.tsv`: scenario table. `web/`: synthetic pages for the fake Internet.
