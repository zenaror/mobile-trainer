# English locale snapshot

`make english` builds a pinned English overlay in `build/en/source` and places the ROM, symbols and map in `build/en`. The root source and default `make` retain the Japanese reconstruction. `make english-check` also runs the symbol, palette, PNG, graphics-export and sprite-chain checks against that source view.

The overlay manifest selects 563 explicitly enumerated source overrides, including translated text, sprites, boxes, graphics binaries and editable PNGs. Common files fall back to 4238 explicitly enumerated, hash-pinned Japanese source files. Both manifest counts reject booleans, negative values and disagreement with their concrete record maps. Git and reference ROMs are not required to build a source archive. Original-owner changes require an explicit parity refresh; the helper does not discover or synchronize new overrides. Manifest paths reject traversal and symlink inputs.

The snapshot derives from fixed MAIN ef41bff1fb24f2239661c230a48500f92bff4559 and published English d0ef9a448d078e6697e2a226ba0f5eab42c16409. Those identifiers retain historical package provenance. The notice-header overlay uses published MAIN73 `2a6f37f358e2fa007611bdab9281a2ce505645c1` as its shared-source baseline. The published MAIN ledger is archival evidence and remains Japanese-qualified; it does not imply English natural-flow evidence. Any later parent change requires another explicit refresh before integration. The preceding EN baseline is `824305546e27f489c16c189876d7100ab3b701f7cd16c6977dc81c1d13b52665`/BFCD. Expected ROM SHA-256 is `1f1c28855ef560e9da4b2f2a3d4d8d9fc74162dff51381f9efc562025c9023a1`, with global checksum E0FC. The static byte recipe defines 997 differences from the preceding EN baseline: 995 notice-header bytes and two checksum bytes. The inherited DEBUG=0 namespace expectation is 15584 labels and 51 constants. DEBUG=1 changes the cache key and recreates the same build/en/source view; it is not a separately retained cache directory. Its namespace needs separate measurement. The Make targets forward the effective RGBASM, RGBLINK, RGBGFX, PYTHON executables and assembler/linker flags; executable variables must name a single executable, with build flags supplied through the flag variables. PYTHON selects the helper and its direct Python checks and is forwarded to Make recipes that use $(PYTHON), including palette-check and png-check. Legacy sym-check and many test/canonical recipes still invoke literal python3 from PATH; forwarding PYTHON does not replace those commands. Default Japanese Make recipes are preserved.

The cache binds all selected inputs, method code, manifest bytes, effective native executable hashes, relevant environment and options. A changed key or missing, added or changed cached build output recreates the source view. Full build output hashes are recorded after successful build and requested checks. Root and view source pins are revalidated against the manifest afterward. Original BIN/PNG timestamps are retained so a fresh copy does not accidentally regenerate committed graphics. Outputs and caches stay under build/en; language payloads are excluded from broad source scanners. This native inventory is not a claim about transitive tool dependencies.

Reuse remains bounded: the first FullHelp page is adapted in a 63-byte slot; complete WholeHelp is not adopted. The manifest retains KEEP1851 as an explicit historical checkpoint ledger from before the notice-header recipe: 995 differences in bank 4B and 856 in bank 71. The overlay selects exactly the 995 bank 4B differences in two alternative notice-header sources; the recipe leaves 856 differences in that same historical graphics cohort, all in bank 71. This finite cohort count does not measure all ZIP discrepancies. This build does not claim full ZIP parity, natural-menu execution, rendering, hardware validation or a mapping between Pokémon names and frames.
