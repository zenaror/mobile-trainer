## Format and bounded target query

Rows contain kind, from_bank, from_pc, to_bank, to_addr, count and first_frame; ret_other also has expected=XXXX. The bank-aware aggregates are SP and shadow-stack qualified, not a chronological instruction stream. The shadow stack and its return matching have finite limits documented in the tracer; coverage and merged dataaccess cannot reconstruct missing dynamic destinations. Entry queries use call/rst/irq/jphl and include RAM destinations. Normal/other/unmatched returns stay separate.

All rows of the restored 19 files have positive counts and nonnegative first frames. A recount of the current SYM's 28 global neutral-only groups found zero entry targets for all 28 in these restored 19 graphs. That query is finite: it does not prove unreachable or exhaustive callers, and it does not exclude raw, computed, interior, unobserved or other-input entries. Names, evidence levels and classifications stay unchanged. The existing dated notes that used the 69/69/50 corpus are retained as history; the new appendices state this candidate's 69/69/69 corpus explicitly.

The current driver recreates each detail directory and deletes a scenario's raw output directory when replaying it. A future driver publish can remove these archived lite graphs; it requires an explicit preservation/republication policy and comparison against the archived byte guards. Archival adoption must not silently rerun scenarios, rewrite old history or change lite/forced definitions.

The transferred ROOT/IND static dependency audit covers 56 local scripts in the finite canonical-37 closure, using local AST imports and conservative literal script/Makefile references. All 147 Python files and the two makefiles match the guarded earlier controls. tools/mapper.py and tools/trace/run_trace.py are outside that finite closure. The mapper is a separate consumer of detail callgraphs, omits RAM/nonhex return destinations and can feed regenerated analysis; it was not run here. Generated fake test scripts, dynamic subprocess expressions, native/external dependencies and arbitrary runtime behavior remain audit limits. This is not a claim that no possible tool can consume the added graphs. No mapper, generator, trace driver, capture or canonical37 was executed for this transfer; config/gen_asm history remains frozen.
