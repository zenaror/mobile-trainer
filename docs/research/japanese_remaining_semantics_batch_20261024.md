### Keyboard page fragment

The normal keyboard writers still establish values `0..3` after initialization. A targeted alias/nearby-writer pass found no alternate `EQU` alias for `wKbdPage=$C2AC`, no literal mirror reference, and no keyboard-local pointer walk to that byte.
