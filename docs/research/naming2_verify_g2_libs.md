## 1. Result in one paragraph

No name was refuted.  3 names were renamed (one because the name promised more than the code does, two because the name pattern of their family says something the code does not do),

idealised without touching the name (section 4).  The mechanical checks all passed: for each of the 150 applied rows the `.sym` address of the new name equals the address of the old
name and of the `Function_BB_AAAA` in it; all "executed at entry in N/64 scenarios (H hits)" figures equal `analysis/coverage_union.tsv`; all 40 `Crystal FunctionXXXX (kind, status)` / local-label
