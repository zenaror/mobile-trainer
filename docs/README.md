# docs/ index

Documentation of the *Mobile Trainer (Japan)* disassembly.  The source is the hand-maintained RGBDS tree at the repository root (`README.md`, `STYLE.md`, `INSTALL.md`); the top-level status is in
[`../REVERSE_ENGINEERING.md`](../REVERSE_ENGINEERING.md).  This directory holds the reference documents and the research notes that carry the evidence behind the statuses (`CONFIRMED` / `PROBABLE` / `HYPOTHESIS`)
written in the source comments.

Evidence lives in these places, from the source outwards:

| where | what |
|---|---|
| `[STATUS]` comments and `; ---- <kind> ... [STATUS] note` headers in the `.asm` files, `ram/*.asm`, `consts.asm` | the last state of every claim, with a short note |
| `docs/research/*.md` (this directory) | the reasoning: method, addresses, retractions, open questions.  **New findings are recorded here and at the code.** |
| `config/symbols/*.tsv`, `config/regions/*.tsv`, `config/ram/*.tsv`, `config/xrefs.tsv` | frozen per-symbol / per-region evidence text (bootstrap tables, `config/README.md`) |
| `analysis/`, `traces/` | machine-readable analysis output and emulator coverage (dynamic evidence) |

## Status of the documents

* **reference (current)**: still describes the ROM or the source as it is.
* **historical**: written while the source was one generated `src/bankNN.asm` per bank (or as output of an analysis tool over the ROM).  The findings and the addresses (`bank:addr`) are still the evidence;
  only the *names* changed: generic `Label_BB_AAAA` labels now appear as local labels `.lAAAA` (or `.loop`/`.done`/`.skip`) inside their function, other neutral names are unchanged, and semantic names adopted
  from the notes are in the source.  Each of these files has a note at the top; find code by address with `grep -rn '; BB:AAAA' --include=*.asm .` or in `build/mobile_trainer.sym`.
  Commands of the frozen bootstrap pipeline in them (`make regen`, `make verify`, `make tree*`, `tools/gen_asm.py ...`) are the record of how the work was done, not instructions for the current tree
  (`make regen`, `verify`, `tree*` refuse to run; `make legacy-check` runs the generator in a temp dir).
